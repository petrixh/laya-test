Laya · part two · document classification

Where Laya Breaks

A 421M non-autoregressive decision model, given 160 business documents and a menu of categories that grows from two to sixteen. It does not break where we expected, and the control that catches it is not accuracy.

Read this first

  • The corpus is invented. All 160 documents were written for this test to be realistic in shape. None is a real message, and no number here transfers to real traffic without re-measuring on real traffic.
  • Small samples. Ten documents per label, forty per tier. A gap under roughly ten points is not a gap.
  • One checkpoint, one backend. Results are not comparable across the torch and MLX builds — the MLX port is an independent FP16 conversion.
  • Written end to end by an LLM with a human steering. Nothing here is peer reviewed.

The expected finding did not replicate

Part one of this project found that option count was the sharpest edge on this model: a two-option question was reliable where a three-option one collapsed. A classifier is just a question with one option per category, so the obvious prediction was that accuracy would fall as the menu grew.

It does fall — but that turns out to be mostly an artefact. A document is only scorable at k when its own gold label is on the menu, so as k grows the document set grows with it, and the labels added later are harder and closer together. Holding the documents fixed and growing only the number of wrong answers on offer separates the two.

Where it actually breaks

The control that needs no baseline: ask the same question with the options rearranged. A model reading the document names the same category however the list is ordered. One keyed on position does not.

Difficulty beats option count

Four tiers, forty documents each. explicit names its own category in plain words. realistic buries the same signal in greetings, a quoted thread and a signature. implicit removes the giveaway vocabulary entirely. adversarial carries the surface vocabulary of a different category — the message headed Re: Invoice #7781 that is really about a download failing.

It gets more confident as it gets more wrong

This one has a mechanism, not just a correlation. Laya derives confidence as normalised Shannon entropy, 1 − H(p)/log(k). The log(k) denominator grows with the menu, so the same amount of real uncertainty maps to a higher reported confidence every time you add a category.

What is actually tunable

The first question anyone asks is what the knobs are. For this model the familiar ones do not exist: predict(state, questions) takes no sampling parameters, and one forward pass is deterministic — the same prompt returned a bit-identical distribution 20 times out of 20. There is nothing being sampled, so there is nothing to sample differently.

Naming more than one category

34 documents carry a second gold label. Only the per-label framing can name more than one, because its scores are independent — a choice question spreads one unit of probability across the menu and can only ever have a single winner. That ceiling is measured here rather than asserted.

What we would tell someone using this

    The confusions are semantically sensible rather than random — training read as product_feedback, procurement as sales, partnerships as sales. Those are genuine near neighbours, which suggests the taxonomy is asking something fair and the model is losing on boundaries rather than on comprehension.
